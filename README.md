# 先等等｜Pause Before You Buy
Responsive clickable prototype for the SDG 12 project.

## Included interaction
1. User voluntarily opens the prototype.
2. Enters product name and approximate price.
3. Selects one of three states: 我真的需要／我想要，但不是必需品／我還不確定.
4. Answers short reflection questions.
5. Makes their own decision now or adds the product to a 24-hour / 72-hour cooling list.

## Run locally
Open `index.html` in a modern browser.

## Publish on GitHub Pages
1. Create a repository and upload `index.html` and `README.md` to its root.
2. Open Settings → Pages.
3. Choose Deploy from a branch, select `main` and `/ (root)`, then Save.
4. Wait for GitHub Pages to provide the public URL.

## Scope and privacy
This is a user-initiated prototype. It does not automatically detect activity on Shopee, Taobao, or other shopping platforms, and it does not read purchase history, account information, or payment data. Cooling-list entries are stored locally in the browser using localStorage. There is no account or cloud sync.
